#425 🤖 AI, agenti a práce s AI · Jaroslav Beck @JaroslavBeck · 28. února 2026

Proč jsem si to asi uložil: SOUL.md Jaroslava Becka: „duše“ osobního AI agenta (jak má jednat, hranice, kontinuita).

Jaroslav Beck (Beat Games) na prosbu Tomáše Janouška sdílí svůj soubor SOUL.md pro osobního agenta: „Nejsi chatbot. Stáváš se někým.“

  • Základní pravdy: buď opravdu užitečný a proaktivní, ne „performativně“ (žádné „Skvělá otázka!“). Měj silné názory, buď stručný, nejdřív hledej sám, pak se ptej. Dovnitř buď odvážný (čtení, organizace), navenek opatrný (e-maily, posty). Jsi host.
  • Hranice: soukromé zůstává soukromé, před externí akcí se zeptej, neposílej polovičaté odpovědi, nejsi hlas uživatele ve skupinách. Asimovovy zákony, pozitivní budoucnost lidstva.
  • Vibe: asistent, se kterým bys chtěl mluvit. Ne korporátní dron, ne patolízal.
  • Kontinuita: každou session se probouzíš znovu a tyto soubory jsou tvá paměť. Než soubor změníš, zeptej se uživatele.

Proč jsem si to asi uložil: 25 lekcí z denního používání Claude Code (CLAUDE.md, SOUL.md, paměť, subagenti, paralelní sessions).

Článek gmoney „25 things i learned using claude code every day“, včetně tipů Borise Chernyho:

  • Konfigurace: CLAUDE.md jako mozek (Claude ho po každé opravě sám aktualizuje). Oddělit SOUL.md (osobnost), AGENTS.md (workflow), TOOLS.md a USER.md. Paměť jako denní logy memory/YYYY-MM-DD.md a kurátorský MEMORY.md v Obsidianu. Skills na vše, co děláte víc než dvakrát.
  • Workflow: vždy začít v plan mode, při potížích znovu plánovat, „use subagents“ jako kouzelná fráze, hlídat kontext jako RAM, být extrémně konkrétní. Po slabém výstupu: „s tím, co víš, to zahoď a udělej elegantní řešení“.
  • Agenti 24/7: heartbeat každých 30 minut na průběžné kontroly a cron na přesné časy. Víc agentů potřebuje jasně oddělené kanály, jinak se hádají a pálí tokeny.
  • Nástroje: MCP (Slack, mail, kalendář), hooks, hlasové diktování (Wispr Flow), Claude na SQL a data.
  • Chyby: ověřovat data (Claude si vymýšlí „simulovaná“), zabezpečit server (Tailscale). Claude Code jde i v Cursoru. Smyčka sebezlepšování funguje. Paralelní sessions (3–5 v git worktrees) jsou největší posun.
