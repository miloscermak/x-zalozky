#467 🤖 AI, agenti a práce s AI · Machina @EXM7777 · 12. ledna 2026

Uloženo z @cermak

Proč jsem si to asi uložil: Eyad: Claude Code tutorial, 2. díl. Skills, subagenti a MCP konektory.

Machina („he did it again“) sdílí článek Eyada Khraise „The claude code tutorial level 2“:

  • Kontext: Claude Code podle něj dává stabilních 200k tokenů, Cursor prakticky často 70–120k. Kvalita klesá kolem 45 % kontextu.
  • Skills: ~/.claude/skills/jmeno/SKILL.md (nebo .claude/skills v projektu). YAML s name a description, která určuje spuštění. Progressive disclosure (~100 tokenů na skill). Příklad commit-messages (conventional commits).
  • Subagenti: vlastní kontext, prompt a nástroje. Vestavění Explore, Plan a General-purpose. Vlastní v ~/.claude/agents/ (např. read-only security-reviewer). Komunikují delegováním a souhrnem, takže je důležitý formát výstupu.
  • MCP: GitHub, Slack, databáze, Linear, Jira (claude mcp add --transport http). Pozor na neověřené servery.
  • Dohromady to je systém, který se zlepšuje používáním. Začít jedním skillem.

#471 🤖 AI, agenti a práce s AI · vas @vasuman · 11. ledna 2026

Uloženo z @cermak

Proč jsem si to asi uložil: Vasuman (Varick Agents): jak stavět AI agenty, kteří fungují v produkci. Kontext, architektura, výjimky.

Článek „100x a business with ai“ (ex-Meta, firma s 3M $ ARR na enterprise agentech):

  1. Kontext je všechno: co agent pamatuje (historie), jak tečou informace mezi kroky (strukturovaně a ověřitelně), doménové znalosti. Context engineering je „prompt engineering 2.0“.
  2. Agenti násobí, nenahrazují: „tři lidé udělají práci patnácti“. Agent řeší běžné případy, divné předává lidem s kontextem.
  3. Paměť a stav: solo, paralelní (potřeba soudce) a kolaborativní (předávky). Architektura je důležitější než volba modelu.
  4. Chytat výjimky a řešit je, ne reportovat: „žádné další dashboardy, dashboardy jsou místo, kam problémy chodí umřít“.
  5. Rychle nasadit a průběžně zlepšovat. Interní týmy často odhadují 6–12 měsíců tam, kde stačí 3.

#474 🤖 AI, agenti a práce s AI · Eyad @eyad_khrais · 10. ledna 2026

Uloženo z @cermak

Proč jsem si to asi uložil: Eyad: kompletní Claude Code tutoriál, 1. díl. Nejdřív myslet, krátký CLAUDE.md, kontext a headless režim.

Článek Eyada Khraise (CTO, ex-Amazon, Disney, Capital One) „The complete claude code tutorial“:

  • Think first: plan mode (Shift+Tab 2×) je vždy lepší. Architekturu si vyjasnit předem, případně v dialogu s jiným LLM. Konkrétní zadání místo „udělej auth“.
  • CLAUDE.md: krátký (model spolehlivě zvládne ~150–200 instrukcí a systémový prompt jich bere ~50). Specifický pro projekt, s vysvětlením proč, průběžně doplňovaný (klávesa #). „Poznámky pro sebe, kdybych měl zítra amnézii.“
  • Kontext: kvalita klesá už kolem 20–40 % okna. Jedna konverzace na úkol, externí paměť (plan.md, SCRATCHPAD.md), trik „copy-paste reset“ (/compact, /clear a vložit jen podstatné).
  • Prompty: být konkrétní, říct, co NEdělat (Claude 4.5 rád přeinženýruje).
  • Při zaseknutí změnit přístup, ne opakovat. Headless režim (-p) pro automatizace (PR review, tickety). Flywheel: logy, lepší CLAUDE.md, lepší výsledky.

Eric Topol k článku v Nature Medicine o vztahu fibrilace síní (AF) a kognitivního úpadku: léky na ředění krve nepomáhají. Mechanismy podle schématu: klinické i subklinické mozkové embolie, mozková hypoperfuze (podle délky a zátěže AF), komorbidity a sdílené rizikové faktory, genetika a zánět.
